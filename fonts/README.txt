====================================================================
LUMEN: CUSTOM FONTS FOLDER
====================================================================

You can download fonts from dafont.com (or any font site) and paste 
the font files (.ttf, .otf, or .woff2) into this folder.

Lumen is already configured in CSS to automatically look for these
file names in this exact folder:

1. Display / Header Font (e.g. "Theri Curls"):
   Paste as:
   - TheriCurls.ttf
   (or theri-curls.ttf, TheriCurls.otf)

2. Secondary / Accent Script Font (e.g. "MTF Queen Of Sketchyland"):
   Paste as:
   - MTFQueenOfSketchyland.ttf
   (or QueenOfSketchyland.ttf, MTFQueenOfSketchyland.otf)

3. Any Other Custom Script Font:
   Paste as:
   - CustomScript.ttf

Fallback:
If no font files are pasted here, Lumen automatically uses Google Fonts:
- "Caveat" (for headings and handwritten display)
- "Gochi Hand" (for accent notes and subheadings)
- "Quicksand" (for clean, warm, readable body text)

Once you paste your font files here, simply refresh your browser!
