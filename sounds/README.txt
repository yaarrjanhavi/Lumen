====================================================================
LUMEN — CUSTOM SOUNDS & ASSETS FOLDER
====================================================================

NOTE: Lumen has a built-in Web Audio API synthesizer that generates
soft pops, bubble bursts, and singing bowl chimes automatically with 
ZERO external audio files needed.

However, if you want to use your own favorite sound files, you can 
place .mp3 or .wav files into this folder:

1. Button Tap Pop:
   - pop.mp3 (or pop.wav)

2. Popping Bubbles:
   - bubble.mp3 (or bubble.wav)

3. Focus Timer / Zen Completion Chime:
   - chime.mp3 (or chime.wav, singing-bowl.mp3)

4. Ambient Background Soundscapes:
   - rain.mp3
   - garden.mp3
   - singing-bowl.mp3 (or soft-hum.mp3)

If these files are present, Lumen will play them; otherwise, it 
seamlessly falls back to its built-in synthesized soothing audio!
====================================================================
